# Changelog

All notable changes to WebMeld are documented here.

## [Unreleased]

## [0.1.1] - 2026-08-12

### Changed

- Show the WebMeld interface in English on non-Chinese pages and Chinese on Chinese pages.
- Add English support to the built-in local styling rules.
- Replace the GitHub Mermaid workflow with a dedicated responsive SVG so diagram controls cannot cover the final step.
- Replace the launch demo with a sharper English 1080p walkthrough and a 1440 × 810 animated preview.

## [0.1.0] - 2026-08-12

### Added

- Visual selection overlay with element identity, dimensions, selector, and HTML preview.
- Natural-language local rules for common page styling requests.
- Bring-your-own OpenAI-compatible Agent configuration and connection test.
- Strict parsing and sanitization of model-generated CSS declarations.
- Live CSS preview with computed-style verification.
- Direction validation for larger and smaller font requests.
- Automatic rollback after failed preview, apply, or persistence.
- Per-page local persistence, undo, and UserCSS export.
- Toolbar action and `Alt+Shift+M` shortcut.
