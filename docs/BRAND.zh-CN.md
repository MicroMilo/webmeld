# WebMeld 品牌规范

WebMeld 的图形由两个类似浏览器界面的色块组成，中间融合成一个白色的 **W**。左右两部分象征产品的核心作用：把用户的设计意图融入眼前真实存在的网页。

[English](BRAND.md)

## 素材

| 文件 | 用途 |
|---|---|
| `assets/brand/logo-mark.svg` | 首选的可缩放产品图标 |
| `assets/brand/logo-lockup.svg` | 横版图标与字标 |
| `assets/brand/logo-lockup.png` | 文档和社交媒体使用的位图版本 |
| `assets/brand/social-preview.png` | GitHub 社交预览图，1280 × 640 |
| `assets/icons/icon-*.png` | Chromium 扩展和小尺寸界面图标 |

## 色彩

| 名称 | 色值 | 用途 |
|---|---|---|
| Meld 紫 | `#7657F6` | 主色块与交互色 |
| 深紫 | `#4A32B8` | 对比色块与层次 |
| 墨色 | `#171A24` | 字标与主要文字 |
| 雾白 | `#F7F5FF` | 浅色品牌背景 |

## 使用规则

- 优先在白色、雾白或其他安静的浅色背景上使用全彩图标。
- 图标四周至少保留其宽度四分之一的留白。
- 极小尺寸直接使用提供的 16 px 图标，不要让扩展清单临时缩放 512 px 文件。
- 不要改变左右色块的颜色、拉伸图标、增加阴影，或在白色融合区域上叠加其他内容。
- 产品名固定写作 **WebMeld**，其中 **W** 和 **M** 大写。

可编辑的 SVG 是品牌素材的源文件；PNG 等位图均为派生文件，可在图标调整后重新导出。
